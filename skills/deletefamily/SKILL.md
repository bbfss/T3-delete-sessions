# 删除当前会话家族

用户实际发送 `/deletefamily` 或直接选择本 Skill 即授权删除**当前会话本身及其全部后代**。仅讨论命令、引用示例或询问原因不授权删除。此命令与保留当前会话的 `/deletesessions`、`/deletesubsessions` 不同。

1. 从宿主和T3官方查询核实当前环境、当前threadId及全部后代；固定完整ID与范围，不用cwd、标题、最近活动或旧脚本--current猜测。当前会话是本次家族根，不能因“执行者保护”永久从最终目标中排除。
2. 先按相邻 [deletesessions](../deletesessions/SKILL.md) 生成和执行**后代阶段**的计划。该阶段的当前会话保护仅用于维持协调及报告，不改变本命令最终包含根会话的范围。
3. 严格先远端后本地：所有远端后代均删除并核验成功，才能删除本地后代。远端离线、失败、未确认或登记关系不完整时停止后续删除，在当前会话报告阻碍，暂时保留根以便重试。不能把部分完成报告成整树已删。
4. 全部后代处理完毕后，准备根节点的最终删除：目标是已核实的当前环境及threadId，调用T3官方在线删除能力，或新版插件delete_family(thread_id=根ID,keep_parent=false,dry_run=false)。不得改用keep_parent=true完成本命令。
5. 根删除会中断当前Agent及其工具连接。因此，最终调用必须交给**已验证不依赖该会话生命周期的执行者**：例如树外已授权执行入口或所属设备独立调度的短脚本。不能把清理worker放进待删子树，不能假定普通后台符号/nohup或当前MCP子进程足以独立。交接只含本次根ID、所属环境、后代完成证据及外部结果路径；不新开推理会话来绕过宿主规则。
6. 在根删除前向用户报告“后代已完成，正在交接当前会话的最终删除”，并给出外部结果位置。独立执行者用官方接口核验根删除结果；当前聊天消失后不能声称还能在原聊天正常回报。只有写入独立回执并核验成功才能算整树完成。

若当前平台没有已验证的独立执行入口，明确报告“后代已完成，根节点最终删除交接受阻”，保留根用于处理；这是执行阻碍，**不是本命令默认保留当前会话**。不得默默退化为deletesubsessions，也不得虚报整树完成。

只处理本次会话家族。原生provider历史、项目文件、worktree与共享服务不因本命令自动物理删除。根节点最终交接与平台验证状态须如实报告。
